QCAUS Secure Account & Data Deletion

Effective date: September 15, 2026

QCAUS Secure v0.1.0 does not create network accounts. There is therefore no server-side QCAUS account or account record to delete in this release.

Current prototype

For local data, uninstall the app or use the operating system's app-data controls to remove application data.

Future account-enabled releases

Before an account-enabled release is submitted to a store, QCAUS Secure will provide a readily discoverable in-app deletion path and this external web resource will be updated to provide an external account/data deletion request path.
