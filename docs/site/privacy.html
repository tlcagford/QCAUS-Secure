QCAUS Secure Privacy Policy

Version 0.1.0

The current QCAUS Secure prototype is primarily local software. It does not operate a QCAUS cloud account or production messaging backend.

Files

The prototype can use the platform file picker to let a user select a file. The current build does not upload the selected file to a QCAUS server.

Messages

Prototype chat messages are held in application memory for the current session and are not transmitted by this build.

Future releases

Networked releases will publish an updated privacy policy before enabling new data collection or account infrastructure.
