QCAUS Secure Privacy Policy

Effective date: September 15, 2026

This policy describes QCAUS Secure v0.1.0, the current local engineering prototype. The prototype does not create a network account and does not transmit chat or file content to a QCAUS server.

Information handled by the current prototype

  • Text entered into the chat interface is held in the current application session.
  • A file selected through the file picker may be read locally so the app can display its name and size.
  • Security-test and QCAUS Lab values are processed locally in memory.

Network services

The current prototype does not provide a QCAUS network messaging backend, cloud file store, advertising network, or analytics service.

Contacts, microphone and camera

The current prototype uses sample contact data and does not request broad device contacts access. It does not implement live voice/video capture and should not request microphone or camera permissions.

Security

The prototype is not an independently audited secure-messaging system. It does not claim absolute, unhackable, or unbreakable security.

Deletion

Because the current prototype does not create a network account, there is no server-side account record to delete. Local application data can be removed by uninstalling the app or using the operating system's app-data controls.

Future network releases

Any release that introduces accounts, network messaging, calls, push notifications, cloud storage, analytics, or third-party processors will publish an updated privacy policy describing the exact data collected, purposes, recipients, retention, and deletion mechanisms before that release.
