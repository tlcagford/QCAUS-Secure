QCAUS Secure — Public Security Beta

TRY TO BREAK IT

QCAUS Secure is a communications-security architecture research project. The beta is intended for independent testing and adversarial analysis.

Do not use the beta for sensitive communications.

What to test

  • Authenticated Adaptive State Recovery (AASR)
  • MITM modification and state-transition authorization
  • Replay and stale-state handling
  • Downgrade resistance
  • State rollback and recovery
  • Malformed-input and fuzzing behavior
