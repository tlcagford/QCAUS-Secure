# Store Submission Checklist

## Google Play

- [ ] Target/compile API 36+
- [ ] Signed AAB
- [ ] Data Safety form
- [ ] Privacy policy URL
- [ ] Store listing
- [ ] Screenshots
- [ ] Content declarations
- [ ] Permission review

## Apple App Store

- [ ] Signed archive
- [ ] App Store Connect record
- [ ] Privacy details
- [ ] Export compliance
- [ ] Screenshots
- [ ] App Review metadata
- [ ] Permissions accurately declared

## Product claims

Use conservative language:

"communications-suite prototype" is appropriate.

Avoid unsupported claims such as "unhackable", "quantum-secure", "FTL", or
"dark-photon communications" for the current binary.
