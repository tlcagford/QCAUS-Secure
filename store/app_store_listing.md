# Apple App Store listing draft

## Name

QCAUS Secure

## Subtitle

Communications prototype with AASR

## Description

QCAUS Secure is a communications-suite prototype with local chat, file
selection, calls and contacts UI, a security-state demonstration using
Authenticated Adaptive State Recovery, and a classical two-field DSP lab.

The current release is a prototype. It does not provide production network
messaging or make claims of unhackable or quantum-secure communication.
