## Description

QCAUS Secure is a research and engineering prototype for communications, file workflows, contact verification, and authenticated adaptive state recovery.

The current release includes:

- local chat interface;
- local file-selection workflow;
- contacts and identity-verification interface;
- voice/video interface prototypes;
- AASR security demonstration;
- QCAUS two-field coherent-signal research lab;
- privacy and legal information.

### Security status

This release has not been independently security audited. It does not claim to be unhackable or unbreakable.

Production secure messaging requires a mature, independently reviewed authenticated protocol, secure identity management, forward secrecy, post-compromise recovery, replay protection, multi-device key management, and secure local key storage. Those production network services are not included in this local prototype.

The QCAUS Lab models classical coherent two-field signals. It does not establish dark-photon communication, FDM communication, faster-than-light communication, reactionless communication, or any other unverified physical effect.
