# Google Play listing draft

## App name

QCAUS Secure

## Short description

Private communications prototype with authenticated adaptive state recovery.

## Full description

QCAUS Secure is a communications-suite prototype focused on a clear security
boundary and auditable state handling.

Features in this release:

- local prototype chat interface;
- local file-selection workflow;
- calls and contacts interface;
- AASR security-state demonstration;
- QCAUS Lab classical two-field DSP demonstration.

This release does not provide production network chat, cloud file transfer,
production voice/video calls, or an audited quantum-secure protocol.

The two-field lab is a classical DSP research model and is not evidence of
dark-photon, FDM, FTL, or reactionless communication.
