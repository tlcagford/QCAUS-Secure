## Full description

QCAUS Secure is a research and engineering communications-suite prototype focused on authenticated adaptive state recovery and resilient communication workflows.

Current release features:

- local chat interface;
- local file-selection workflow;
- contacts and identity-verification interface;
- call and video interface prototypes;
- AASR security demonstration;
- QCAUS two-field coherent-signal research lab;
- privacy and legal information.

### AASR

Authenticated Adaptive State Recovery (AASR) separates channel observations from authorization of cryptographic state changes. A degraded or anomalous channel can trigger a recovery attempt, but a channel observation cannot by itself establish a new trusted state.

### Important security status

This release is a prototype and has not been independently security audited. It is not an "unhackable" or "unbreakable" communications system.

The network messaging backend, production identity/key management, and production voice/video transport are not included in this local prototype release.

The QCAUS Lab is a classical coherent two-field research model. It does not establish dark-photon communication, FDM communication, faster-than-light communication, reactionless communication, or any other unverified physical effect.
