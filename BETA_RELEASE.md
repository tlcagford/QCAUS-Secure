# QCAUS Secure — Public Security Beta

## Purpose

This release is an open security research exercise.

### TRY TO BREAK IT

Researchers are encouraged to:

- inspect the source;
- run the tests;
- mutate protocol/state inputs;
- fuzz parsers;
- test replay;
- test MITM modifications;
- test downgrade paths;
- test recovery;
- inspect the trust boundaries;
- challenge the architecture itself.

## Current status

The application is a prototype/reference implementation.

It does not yet provide a production network messaging service.

The current two-field research component is a classical coherent signal/DSP model. It is not evidence of dark-photon communication, FDM communication, FTL communication, or reactionless communication.

## Safety

Do not use the beta for confidential, financial, medical, military, emergency, or safety-critical communications.
